Community Online Tools — UI Component Reference

Visual reference for every layout/widget COT uses. The dark navy background is COTSurface; every widget renders against it. This mockup is a flat HTML/CSS approximation of the real DayZ widgets defined in JM/COT/GUI/layouts/uiactions/*.layout.

Window chrome — windowbase.layout

Every COT module form is wrapped in this chrome: drag-to-move title bar with title text, pin / minimize / close icon buttons.

Player Manager
Form content goes here. Resize handles surround the window on all 8 edges/corners (invisible 5-10 px hit areas, with a 3 px blue highlight on hover).

Buttons

UIActionButton
Standard rectangular button. SetColor() for emphasis (primary/success/danger).
UIActionImageButton (icon-only, 32×32)
Used for refresh, delete-icon, and any compact toolbar action.
UIActionNavigateButton
Used in sidebar / breadcrumb navigation. Icon left, chevron right.

Toggles & checkboxes

UIActionCheckbox (square)
Multi-select / independent boolean. Default checkbox in COT (backed by UIActionToggle).
UIActionToggle (round / radio)
Single-choice variant of the same widget. Set with SetRound(true).
UIActionToggleSwitch
Animated horizontal switch for settings.
Auto-refresh enabled
Show ESP overlay
Disabled state
A semi-opaque overlay greys out any action widget. The greying is the same shade across the whole UI.
